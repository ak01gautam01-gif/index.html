# Akhilesh Gautam — Portfolio

A responsive, dark-theme portfolio website made with plain HTML, CSS, and JavaScript.

## Preview on your computer
1. Extract the ZIP file.
2. Open the `index.html` file in Chrome or another browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `akhilesh-portfolio`.
2. Upload `index.html` to the repository root and commit the changes.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site; the URL will appear in the Pages section.

## Before publishing
- The LinkedIn button currently points to the general LinkedIn website. Replace `https://www.linkedin.com/` in `index.html` with your full profile URL.
- Review the email address and other personal details before publishing.
